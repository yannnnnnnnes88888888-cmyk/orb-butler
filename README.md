# 光球管家 · Android 版（Orb Butler）

把之前那个「桌宠任务管家」网页，打包成了**能直接下载安装的安卓 App**。
你提的四个点，都是用原生能力做的，不是浏览器里糊出来的：

| 你的要求 | 实现方式 |
| --- | --- |
| 能直接下载安装的软件 | 标准 Android 工程，`assembleRelease` 出 APK，装到荣耀手机上就是个 App |
| 桌宠显示在软件上方 | `SYSTEM_ALERT_WINDOW` 悬浮窗：`FloatingService` 用 `TYPE_APPLICATION_OVERLAY` 画一个真·光球，浮在微信/抖音/桌面上面 |
| 不用时收纳在不显眼的地方 | 8 秒不动自动贴边 + 缩成半透明小球；长按也能立刻收纳；通知栏常驻条上有「收纳」按钮 |
| 真的能通知，不是浏览器通知 | `POST_NOTIFICATIONS` + 三个原生通知渠道 + `AlarmManager` 精确闹钟，App 划掉了、屏幕锁着也会响 |

核心逻辑（任务解析 / 排程 / DeepSeek 对话 / 主动催办）全部复用你已经调好的那一套网页，
现在跑在 App 内置的 WebView 里，并且跟原生打通了：

- 网页一保存任务 → 同步给原生 → 立刻排闹钟（截止前 30 分钟 + 到点 + 逾期）
- 网页里原本的 `Notification` 调用 → 直接换成**系统通知栏**
- 每天 09:00 主动问「今天想搞定什么？」；15 分钟自检一次，发现逾期/卡住就催
- 提醒触发时，悬浮光球会变色 + 加快呼吸

## 一、拿到 APK（三条路，任选）

> 说明：当前沙箱环境**访问不了 dl.google.com / Maven / GitHub**，无法在这里编译。
> 所以请走下面任意一条，都是几分钟的事。

### 路线 A：GitHub Actions 云编译（推荐，不用装任何东西）

1. 把整个 `orb-butler/` 目录传到 GitHub 新仓库（网页上传即可，或 `git push`）
2. 打开仓库 → **Actions** → 左侧 `构建光球管家 APK` → **Run workflow**
3. 大约 3–5 分钟跑完，点进去最下面的 **Artifacts → orb-butler-apk** 下载
4. 压缩包里有 `app-release.apk`（正式签名，可直接装）和 `app-debug.apk`

> 想更省事：打一个 tag（`v1.0`）推上去，会自动发到 Release 页面，手机浏览器打开就能下。

### 路线 B：自己电脑上编译

需要 JDK 17 + Android SDK（装个 Android Studio 就有了）：

```bash
cd orb-butler
export ANDROID_HOME=$HOME/Android/Sdk   # 按你的实际路径改
./build.sh
```

### 路线 C：Android Studio 直接打开

`File → Open → 选 orb-butler 目录` → 等 Gradle 同步 → `Build → Build Bundle(s)/APK(s) → Build APK(s)`。

## 二、装到荣耀手机上（必做，不然光球/通知不出来）

装完 APK 后，按顺序做这 4 步（荣耀 Magic UI / MagicOS 大同小异）：

1. **允许安装未知应用**
   安装时若提示，按提示允许；或在 `设置 → 安全 → 更多安全设置 → 安装未知应用`，给「文件管理 / 浏览器」打开开关。

2. **悬浮窗：显示在其他应用上层**（没有它光球出不来）
   `设置 → 应用 → 应用管理 → 光球管家 → 权限/显示在其他应用上层` → 打开。
   App 里也有直达按钮：顶部「设置 → 悬浮窗 → 去开启」。

3. **通知权限**（没有它到点不弹）
   App 首次打开会弹系统授权框，点「允许」。
   没弹就在 `设置 → 通知和状态栏 → 光球管家`，把「允许通知」打开，
   并进「通知类别」确认 `任务提醒与催促` 是**重要/高优先级**（这样才会响铃+震动）。

4. **后台与省电**（不然会被系统杀掉、提醒延迟）
   - App 里「后台无忧 → 去设置」→ 选**允许/不优化**
   - `设置 → 电池 → 应用耗电管理 → 光球管家` → 打开「允许后台运行 / 允许自启动 / 允许关联启动」
   - `设置 → 应用 → 光球管家 → 通知管理` 保持开启
   - 多任务界面把光球管家**向下锁一下**（加锁图标），防止一键清理被划掉
   - Android 12+ 记得点「精确闹钟 → 去开启」（荣耀路径：设置 → 应用 → 光球管家 → 闹钟和提醒）

## 三、日常怎么用

- **点光球**：打开主界面（记待办、看排程、和 DeepSeek 聊）
- **拖光球**：换位置，位置会被记住
- **长按光球 / 放着不动 8 秒**：自动贴到屏幕边缘、缩成半透明小光点（不遮挡内容）
- **点一下收纳后的小光点**：弹回原位
- **通知栏常驻条**：有「收纳 / 打开 / 退出」三个按钮，随时控制光球
- **设置里的「开机自启」**：勾上后开机自动把光球和提醒接回来

## 四、工程结构

```
orb-butler/
├── app/src/main/
│   ├── AndroidManifest.xml          权限与四大组件
│   ├── assets/index.html            你原来那套界面（已注入原生桥接脚本）
│   ├── java/cn/workbuddy/orb/
│   │   ├── MainActivity.java        主界面 + 权限引导 + JS 桥（OrbNative）
│   │   ├── FloatingService.java     悬浮光球：拖动 / 点击 / 长按 / 自动收纳
│   │   ├── OrbView.java             Canvas 手绘光球（无图片依赖）
│   │   ├── Notifier.java            通知渠道 + 系统通知 + 精确闹钟
│   │   ├── ReminderReceiver.java    15 分钟自检：逾期/快到点/每日盘问
│   │   ├── BootReceiver.java        开机 & 更新后自动恢复
│   │   └── Prefs.java               任务快照 / 光球位置 / 开关
│   └── res/                         图标、布局、主题
├── app/build.gradle                 minSdk 26，targetSdk 34，零第三方依赖
├── .github/workflows/android.yml    云编译 APK
└── build.sh                         本地一键构建
```

**零第三方依赖**（只用系统 API），所以编译快、包体小（约 300KB + 网页 130KB）。

## 五、常见问题

| 现象 | 怎么解决 |
| --- | --- |
| 光球不出现 | 悬浮窗权限没开（见第二步第 2 条）；开了还不出就回 App 点「启动光球」 |
| 通知不弹 | 通知权限没开，或渠道被设成「静默」；到系统通知设置里把 `任务提醒与催促` 调成重要 |
| 到点不准时 | 开「精确闹钟」+「忽略电池优化」；荣耀/华为对后台管控严格，这两项必开 |
| 一键清理后失效 | 多任务界面给 App 加锁；并打开「允许后台运行」「自启动」 |
| DeepSeek 连不上 | App 需要联网权限（已在清单里声明）；API Key 在设置页填一次就会一直存着 |
| 想备份任务 | 设置页「导出备份」，会存成 `下载/orb-butler-backup-*.json` |

## 六、隐私

- DeepSeek API Key 只存在本机（网页端做了混淆存储），不上传任何服务器
- 任务数据只在本机 + 通知/闹钟，不联网同步
- 需要的权限只有：悬浮窗、通知、精确闹钟、振动、后台运行、联网
